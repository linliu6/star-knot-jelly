# Star Knot Jelly · 星结掌心果冻

A mobile and desktop tactile jelly experience. This repository contains the built website for GitHub Pages.

- Play: https://linliu6.github.io/star-knot-jelly/
- Desktop Inspector: https://linliu6.github.io/star-knot-jelly/?mode=editor
- Three touch variants, four sound categories, local parameter storage.
- iPhone: open in Safari, then Share → Add to Home Screen for standalone display. Tap once to enable sound.

The website is contained in `star-knot-pages.zip`; the Pages workflow extracts and publishes it.
