# Jelly Play

A tiny tactile playground. Press, stretch and listen.

[Play on phone or desktop](https://linliu6.github.io/star-knot-jelly/) · [Open Inspector](https://linliu6.github.io/star-knot-jelly/?mode=editor)

Version 1.0.3. A clean, icon-only scene with English settings and three textures: Classic, Soft and Crisp. Touch the jelly to enable audio. No login required.

`star-knot-pages.zip` contains the built website. The existing Pages workflow publishes it. Derived from mesq's Jelly Painting. Original scene and audio provenance are preserved in the deployed `credits.json`. No general reuse license is granted for upstream artwork or audio assets.
